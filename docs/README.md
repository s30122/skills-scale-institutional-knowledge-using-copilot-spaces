# OctoAcme Project Management Docs

歡迎使用 OctoAcme 專案管理文件索引。
本 README 作為 OctoAcme 專案管理流程的入口，幫助新成員快速了解我們的工作節奏、主要產出與責任分工。

簡短流程概述

- 啟動 (Initiation)：確認問題與目標、識別利害關係人、建立 Project One-pager，決定是否進入規劃。
- 規劃 (Planning)：拆解工作成可交付項、估算與優先排序、定義里程碑與測試策略、建立風險登錄。
- 執行與追蹤 (Execution & Tracking)：透過短會、交付同步與 Pull Request 流程持續交付，使用專案看板管理工作流，並以度量（velocity、burn-down、成功指標）監控進度。
- 風險與溝通 (Risk & Communication)：維護風險表、定期向利害關係人更新狀態，並依情況升級問題。
- 發佈與部署 (Release & Deployment)：遵循發佈檢查清單、執行 smoke tests 與回滾計畫，並發布變更通知與釋出說明。
- 回顧與持續改善 (Retrospective & CI)：在里程碑或 sprint 後回顧，產出可執行的改善項目並追蹤其影響。
- 角色與人物誌 (Roles & Personas)：明確定義 PM、PdM、開發、QA 與利害關係人的職責與溝通方式。

如何使用這份文件

- 請在專案啟動時將此 README 加入專案的入口，確保利害關係人與團隊都能快速找到相關流程。
- 若需讓 Copilot Spaces 使用特定文件作為上下文，可將該文件加入 `.copilot/` 或在專案 README 標註位置。
