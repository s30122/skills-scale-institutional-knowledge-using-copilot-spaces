# OctoAcme Project Management Docs

歡迎使用 OctoAcme 專案管理文件索引。
此 README 作為 OctoAcme 專案管理流程的入口，幫助新成員快速了解我們的工作節奏、主要產出與責任分工，並提供到各流程文件的快速連結。

簡短流程概述

- 啟動 (Initiation)：確認問題與目標、識別利害關係人、建立 Project One-pager，並決定是否進入規劃階段。
- 規劃 (Planning)：拆解工作成可交付項、估算與優先排序、定義里程碑與測試策略、建立風險登錄與依賴清單。
- 執行與追蹤 (Execution & Tracking)：以短會、交付同步與 Pull Request 流程持續交付；使用專案看板管理工作流，並以度量（velocity、burndown、success metrics）監控進度與品質。
- 風險與溝通 (Risk & Communication)：維護風險表、定期向利害關係人更新狀態；依情況啟動升級/事件處理流程。
- 發佈與部署 (Release & Deployment)：遵循發佈檢查清單／CI 驗證、執行 smoke tests、準備回滾計畫並發布變更通知與釋出說明。
- 回顧與持續改善 (Retrospective & Continuous Improvement)：在里程碑或 sprint 後回顧，產出可執行的改善項目並追蹤其影響。
- 角色與人物誌 (Roles & Personas)：明確定義 PM、PdM、開發、QA 與利害關係人的職責、決策與溝通方式。

如何使用這份文件

- 在專案啟動時將此 README 作為流程入口，確保利害關係人與團隊可快速找到相關流程與檢核表。
- 若要讓 Copilot Spaces 或其他工具使用特定文件作為上下文，請將該文件加到 `.copilot/` 或在專案 README 標註位置。
